# MicroStudy ✦

Мобильный тренажёр по микроэкономике для подготовки к экзамену.

## Что есть в версии 1.0

- **40 вопросов** из двух фото пробного экзамена: 30 Multiple Choice и 10 True/False.
- Разбор на русском, оригинальные вопросы на английском.
- **Flashcards** — переворот карточки, «знаю» и «повторить».
- **Practice** — тесты с мгновенной обратной связью.
- **Exam** — все вопросы в случайном порядке, таймер 45 минут.
- **Review** — повторение ошибок и интервальные карточки (через 1, 3, 7, 21 день).
- **Dashboard** — освоение тем, точность, серия занятий.
- Фильтры по темам, новые/ошибки/пора повторить, поиск.
- Локальное хранение прогресса, экспорт/импорт JSON; без аккаунтов и базы данных.
- Адаптация для телефонов, планшетов и ПК.

### Что важно знать

1. Номера на листах пробника имеют ошибки: №22 указан дважды, №29 пропущен, №32 указан дважды. В данных приложения есть собственные уникальные ID и сохранён оригинальный номер.
2. **MC #26**: на фотографии часть варианта D не читается, поэтому правильность ответа может быть неоднозначной. В приложении вопрос отмечен ⚠.
3. **True/False #34**: слово "always" делает утверждение про externalities спорным, хотя в учебной модели ожидается True. Добавлено пояснение.
4. Расчётные задачи и эссе *не входят* в эту версию.
5. Прогресс хранится в **localStorage браузера отдельно на каждом устройстве**. После очистки браузера он удалится, если не экспортировать файл. Синхронизации между устройствами нет.

## Публикация: GitHub Pages (бесплатно)

Приложение полностью статическое, сервер для него необязателен.

Если код находится в \`ssuiun/projects/microeconomics-trainer/\`:

1. В репозитории **Settings → Pages** настрой источник GitHub Pages.
2. В качестве источника можно использовать GitHub Actions. Создай workflow, который публикует содержимое папки \`microeconomics-trainer\`, или опубликуй весь репозиторий через **Deploy from a branch → main → / (root)**.
3. После успешной публикации, если опубликован весь репозиторий, путь приложения: \`https://ssuiun.github.io/projects/microeconomics-trainer/\`.
4. Открой этот URL на телефоне. Отправь его одногруппникам.

**Важно:** ссылка начинает работать только после включения GitHub Pages и успешной публикации.

## Публикация: Railway / Render / VPS

1. Подключи репозиторий \`ssuiun/projects\`.
2. В настройках сервиса задай **Root Directory:** \`microeconomics-trainer\`.
3. **Start Command:** \`npm start\` (или \`node server.js\`).
4. Сервер автоматически использует \`process.env.PORT\`; ручная настройка порта не требуется.
5. Включи публичный домен в настройках хостинга; проверь \`/health\` для healthcheck.
6. Раздай HTTPS-ссылку одногруппникам. У каждого прогресс будет независимым.

Для VPS:
\`\`\`bash
cd microeconomics-trainer
PORT=3000 npm start
\`\`\`
Настрой reverse proxy (Nginx/Caddy) и HTTPS.

## Конфиденциальность

Личные данные и аккаунты не собираются. История ответов хранится в памяти браузера и не отправляется на сервер. Экспортируемый JSON может содержать сведения о прогрессе; передавай его только тем, кому доверяешь.
